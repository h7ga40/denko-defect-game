# Current Status

更新日: 2026-07-19

## 現在の目標

当面は、候補問題の工作物が完成した後に欠陥を探す「施工チェックゲーム」を完成させる。

最終的には、支給部材の確認、複線図の作成、電線加工、器具への結線、ボックス内接続、完成確認までを順番に操作できる作業シミュレーションへ拡張する。

## 実装済み

- 施工チェック、複線図、欠陥判定の3モード
- 初期画面は施工チェック
- 令和8年度候補問題No.1～No.13に対応した学習用簡略複線図
- 複線図のケーブル区間を芯線色データから黒・白・赤・緑・青の平行線として表示
- 候補問題ごとの想定支給部材表示（電線長・本数、器具数量、接続材料数量）
- HOZAN想定図を基にした全13問の器具間寸法表示
- 支給電線IDと加工後ケーブル区間の1対N関連付け、およびHOZAN施工寸法ルールによる切断長算出
- 支給電線の参照、種別、導体径、芯数、本数位置、切断長合計の検証
- No.3のアウトレットボックス1～2をVVF 1.6mm 3心、アウトレットボックス2～タイムスイッチをVVF 1.6mm 2心として管理
- No.3タイムスイッチのS1・S2・L1端子結線と、S2端子への白線2本接続を器具結線データとして管理
- No.7のアウトレットボックス1～2をVVF 1.6mm 3心、4路スイッチ側をVVF 1.6mm 2心2本として管理
- 候補問題、接続部、欠陥位置のランダム出題
- URLクエリー candidate で候補番号を固定し、seed で欠陥位置・種類・接続ミスを再現
- 複線図上の部品本体を直接選択
- 複線図では部品略号を許容し、施工チェック・欠陥判定の詳細表示では正式名称を使用
- 詳細SVGでは導体を器具端子まで連続して描画し、意図的な未接続だけを欠陥として表示
- 器具端になるランプレセプタクル、スイッチ、コンセントなどは片側配線とし、複線図の接続点・ボックスがある方向から進入表示
- Panasonic・未来工業の2D CADを寸法参照に使い、CADそのものを変換せず独自の詳細SVGを作成
- ランプレセプタクル、引掛シーリングローゼット、埋込連用タンブラスイッチ（片切・3路・4路）、遮断器、コンセント、取付枠のCAD参考形状
- アウトレットボックスとジョイントボックスを選択し、内部配線図を表示
- ボックス端のケーブルごとに各心線を一意なIDで管理
- 各心線の正しい結線IDと、2～4芯の結線グループを管理
- 候補問題別の明示結線と、未入力時の推定結線に対応
- 正しい結線と施工結果を分離し、心線ごとの実際の接続先を管理
- 2つの結線間の心線入替えと、接続すべき心線の未接続を施工チェックへ追加
- 誤結線は影響する2結線を採点し、未接続心線は結線手前で止まる遊び線として表示
- ボックス内SVGを、外周ケーブル、内周折曲点、中央周辺の結線部による放射状配置へ変更
- 心線を実際の施工先まで連続表示し、誤結線の交差経路と未接続の遊び線を可視化
- 電線太さ、線色、リングスリーブサイズ・刻印、差込形コネクタ極数の保持
- ケーブル種別、芯数、芯線色、区間長、両端のシース剥ぎ長・芯線ごとの絶縁被覆ストリップ長を管理
- ボックス内SVGでシース剥ぎ長と絶縁被覆ストリップ長を描画寸法へ反映
- 器具ごとの端子グループ数、端子名、差込口数、結線対象・選択対象を一元管理
- 端子ごとの物理差込口数と接続可能心線数を分離し、端子台の1端子2線接続に対応

- ボックス使用穴、ゴムブッシング、管挿入、絶縁ブッシング、ロックナットの欠陥SVG
- ボックス内接続と直接選択器具の全体から欠陥を2～3件抽選
- 最後の完了ボタンで一括採点
- GitHub ActionsによるGitHub Pages公開

## 部品データの管理

CandidateDeviceは、処理上の大分類をtype、具体的な部品記号をvariantで管理する。

主なvariant:

- ランプレセプタクル、引掛シーリングローゼット、確認表示灯
- 片切、3路、4路、複合スイッチ
- 露出形、接地極付、20A接地極付、EETコンセント
- 配線用遮断器、漏電遮断器
- タイムスイッチ、自動点滅器
- 端子台、接地端子、電動機端子

リングスリーブと差込形コネクタは複線図から直接選ばず、ジョイントボックスまたはアウトレットボックスの内部で選択する。

## 選択と採点

- 旧来の破線選択枠は廃止
- 部品本体の輪郭色と状態マーカーで選択状態を表示
- Androidで押しやすいよう、部品の背面に透明なタップ領域を配置
- 選択直後には正誤を表示しない
- 回答済み、選択中、正解、不正解を別状態として保持
- 施工省略部、電動機、負荷器具は直接選択の出題対象から除外

## 現在の制約

- 複線図は公式図そのものではなく、アプリ用の学習用簡略図
- 支給部材の数量・長さは過去出題例を基にした想定値であり、本試験では変更される可能性がある
- 支給部材の使用要否・使用箇所は問題要素として表示していない
- 候補問題No.1～No.13のボックス内結線は芯位置による推定値で、公式施工条件の完全再現ではない
- 放射状配線は実装済みだが、候補問題No.1～No.13の結線自体は芯位置による推定値
- 器具間寸法と切断長はHOZANの過去出題例に基づく想定値であり、当日の施工条件では変わる可能性がある
- タイムスイッチと自動点滅器は端子台形状・端子台欠陥テンプレートで代用する
- 電動機と負荷器具は施工省略記号として複線図だけに表示し、選択・結線・採点の対象外とする
- Android Chromeで候補問題No.1～No.13の実機回帰確認が必要
- 施工チェックの進行状態は再読み込みでリセットされる

## 作業シミュレーションへの拡張案

完成後の欠陥探しを安定させてから、次の段階で実装する。

1. 支給部材の確認と使用部材の選択
2. 単線図から複線図への変換
3. ケーブル種類、長さ、芯線の選択
4. 外装・絶縁被覆の剥ぎ取り
5. 器具端子への結線と極性確認
6. リングスリーブまたは差込形コネクタによる接続
7. ボックス、連用取付枠、器具の組み立て
8. 完成品の自己点検と採点

作業シミュレーションでは、操作履歴を工程データとして保存し、最終形だけでなく途中の誤操作からも欠陥を判定できる設計が必要になる。現在のtype、variant、DefectTypeは、その工程データから完成状態を生成する際にも再利用する。
