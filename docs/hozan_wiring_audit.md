# HOZAN結線図との差異確認

## 目的

HOZANが公開している候補問題No.1～13の結線図を基準に、ゲーム内のケーブル芯線、ジョイント部の接続グループ、器具端子結線を明示データ化する。

参照画像は `D:\ElectricalTechnician\_Ref\HOZAN結線\No.1.jpg` ～ `No.13.jpg` に保存している。画像自体はリポジトリ外の参照資料とし、実装には接続関係だけを転記する。

## 実装方針

- ボックスへ入る全ケーブルに安定したIDを付ける。
- `boxWirings` でケーブルIDと芯線番号の接続グループを明示する。
- HOZAN図の青い圧着表示に合わせ、今回の基準結線は `ring_sleeve` とする。
- リングスリーブのサイズと刻印は、接続する心線の太さ・本数から既存ロジックで算出する。
- タイムスイッチ、端子台、自動点滅器は `deviceWirings` と相互に整合させる。
- 複線図の見た目とボックス詳細図が同じケーブル構成を共有する。

## 注意事項

HOZAN図で器具内部の渡り線として描かれている線は、ボックス内の接続グループへ重複して登録しない。取付枠内の渡り線と端子への複数線接続は、`mountingFrames.jumpers` または `deviceWirings` で管理する。
