# 欠陥画像と参考写真の対応一覧

## 表示と再生成

- 出力先: `tmp/image-audit/index.html`
- 再生成: `npm run audit:images`
- 対応データ: `scripts/defect-references.mjs`
- 生成処理: `scripts/generate-defect-gallery.mjs`
- 機械可読の照合結果: `tmp/image-audit/reference-mapping.json`

以前の4視点を一枚にまとめた静止画像ではなく、欠陥ごとに「参考画像・正面・背面・左側面・右側面」を並べる。図を選択すると拡大表示し、参考写真を選択すると元の画像全体を開く。部品名・欠陥名と実装状況で絞り込める。

## 参照と対応基準

参照元は[でんブロ「第二種電気工事士技能試験の欠陥まとめ」](https://electrical-worklife.com/2025/06/15/defect/)。本文の16画像に含まれる番号付きの56例を個別の行として登録する。写真は元画像の該当列を表示し、出典と元画像へのリンクを付ける。記事内の別記事リンク先は今回の照合対象に含めない。

- **対応画像あり**: 同じ器具・欠陥の出題がある。描画の正確性まで保証する表示ではない。
- **類似・要確認**: 同系統の出題はあるが、参考写真と端子や欠陥の条件、表示の精度が異なる。差異を行内に記す。
- **欠陥画像なし**: 該当する実装を確認できない。参考写真のみ表示し、4視点分の欄を空欄表示にする。
- **参考画像なし**: 既存の実装図だが、今回の参照記事内に対応する例がない。削除せず末尾に置く。

特に、遮断器のN・L逆接続と電源側・負荷側の取り違え、シースの縦割り残りと外装の切り傷、リングスリーブ先端の突出と根元の裸銅線の長さは別の欠陥として扱う。

2026-09-06時点では、参考56例のうち対応画像あり24例、類似・要確認4例、欠陥画像なし28例。対応する参考写真のない既存画像30行を加え、全86行。

## 描画と管理

2026-09-08更新: 既存の輪づくり・電線加工・リングスリーブ・差込形コネクタの表示を改善。未実装の問題は追加していない。両モードの接続材図を共通化し、電線の片側挿入、本数・太さ、筒内の位置を保持する。別視点は内部構造を展開した模式断面を含むため、実物の外観写真とは区別する。回帰確認は`npm run check:visuals`。

欠陥判定の34問と、施工チェックのケーブル・接続材20種類をすべて保持する。露出形コンセントの極性・ねじ緩みなど、参考写真に対応する施工チェックの器具図も追加する。施工チェックは実際の生成結果から抽出し、候補問題番号と再現シードを表示する。正常な図を未実装欠陥の代わりには使用しない。

施工チェックの器具図はアプリ本体の`DirectDeviceDiagram`を共有し、一覧だけ別の図になることを避ける。参考図は照合資料であり、採点基準の自動更新や新しい欠陥問題の追加は行わない。

写真のキャッシュと生成HTMLはGit対象外の`tmp/`内に置き、公開アプリやビルド結果には含めない。対応データと生成処理だけをバージョン管理する。写真キャッシュのない環境では生成時に参照サイトへの接続が必要。今後の再生成には旧`tmp/audit-images.mjs`ではなく上記のコマンドを使う。
## 2026-09-09 の画像更新

引掛シーリングローゼットの丸形・角形、埋込器具の端子、埋込連用取付枠の固定爪と配置を改善した。既存問題のみが対象で、「欠陥画像なし」の項目は追加していない。丸形と角形は同じ接続状態の形状比較であり、2個の器具の出題ではない。側面などは観察用の透視・展開を含む模式図として表示する。

端子数・色・固定爪・配置の検証は `node scripts/check-fitting-visuals.mjs` で実行できる。
